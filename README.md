# Round Hill Entertainment website

Static website for `roundhillentertainment.com`, designed for GitHub-connected Cloudflare Pages hosting.

## Public pages

- `/` — one-page company website
- `/sms-consent/` — public evidence for verbal and SMS opt-in
- `/sms-terms/` — SMS Terms and Conditions
- `/privacy/` — Privacy Policy with mobile-data protections

## Cloudflare Pages settings

- Framework preset: None
- Build command: leave blank
- Build output directory: `/`
- Root directory: `/`

After the first deployment, add `roundhillentertainment.com` and `www.roundhillentertainment.com` as custom domains.

## Twilio campaign URLs

- Privacy Policy: `https://roundhillentertainment.com/privacy/`
- Terms and Conditions: `https://roundhillentertainment.com/sms-terms/`
- Opt-in evidence: `https://roundhillentertainment.com/sms-consent/`

Verify all three in a private browser window before resubmitting the existing A2P campaign.
